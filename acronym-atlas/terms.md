# Initial Acronym / Term Research

## GNU

GNU's Not Unix.

Recursive acronym associated with the GNU Project.

Relevance:
- free software
- copyleft
- GPL
- operating-system architecture
- GNU/Linux

## Linux

Not an acronym.

Linux is the kernel at the center of the Linux ecosystem.

Relevance:
- kernel architecture
- distributed systems
- networking
- GPLv2
- Android foundation

## Android

Android is a Linux-based operating-system/platform ecosystem.

Relevance:
- AOSP
- Linux kernel
- modularity
- open source
- mobile computing

## AOSP

Android Open Source Project.

Relevance:
- open-source platform
- Git/Gerrit
- contribution workflows
- Android/Linux architecture

Relevance:
- licenses
- copyrights
