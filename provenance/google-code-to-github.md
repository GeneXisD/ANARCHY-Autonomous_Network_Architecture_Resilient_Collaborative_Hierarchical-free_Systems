# Google Code → GitHub Historical Provenance

Research target:

Determine how source projects historically moved from Google Code into later
Git/GitHub repositories.

Questions:

- Was the migration manual or automated?
- What repository format was involved?
- What metadata was preserved?
- Were commits preserved?
- Were authors preserved?
- Were timestamps preserved?
- Were issue/wiki records preserved?
- Was licensing metadata preserved?
- What was the original Google Code project?
- What was the destination repository?
- Can identical source files be cryptographically correlated?

Important:

A hosting migration is not automatically a transfer of copyright ownership.
Technical provenance and legal ownership must be analyzed separately.
