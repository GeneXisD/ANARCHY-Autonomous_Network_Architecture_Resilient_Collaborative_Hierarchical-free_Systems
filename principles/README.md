# ANARCHY Principles

Initial principles for research and design:

1. Local autonomy
2. Network interoperability
3. Modularity
4. Resilience
5. Graceful failure
6. Collaboration
7. No mandatory permanent central authority
8. Explicit trust
9. Delegatable authority
10. Revocable authority
11. Open interfaces
12. Reproducible artifacts
13. Verifiable provenance
14. License transparency
15. Attribution preservation
16. Interoperability across implementations
17. Separation of technical provenance from legal ownership
