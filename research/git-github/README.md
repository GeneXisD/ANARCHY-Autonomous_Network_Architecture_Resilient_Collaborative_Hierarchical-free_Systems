# Git / GitHub Research

Git provides content-addressed version history.

Research:

- commits
- trees
- blobs
- parent relationships
- object IDs
- SHA hashes
- author metadata
- committer metadata
- timestamps
- branches
- tags
- remotes
- forks
- signed commits
- GitHub events
- GitHub Archive

Technical history is evidence of provenance, but is not automatically proof
of legal ownership.
