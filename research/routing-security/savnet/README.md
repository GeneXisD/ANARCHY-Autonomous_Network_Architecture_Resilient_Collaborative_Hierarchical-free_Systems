# SAVNET

SAVNET research concerns Source Address Validation in intra-domain and
inter-domain networks.

Key architectural idea:

Independent networks can exchange SAV-related information so that each
network can improve its local validation decisions.

ANARCHY relevance:

- autonomous participants
- distributed information
- trust
- interdomain collaboration
- resilience
- incremental deployment

Primary IETF source:

https://datatracker.ietf.org/doc/draft-wu-savnet-inter-domain-architecture/
