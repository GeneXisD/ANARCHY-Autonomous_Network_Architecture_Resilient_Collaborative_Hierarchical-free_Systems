# Routing Security

ANARCHY research into secure autonomous and interdomain networking.

## Major branches

### BGP

Border Gateway Protocol.

Research:

- autonomous systems
- path-vector routing
- route advertisements
- route leaks
- prefix hijacking
- policy
- interdomain routing

### RPKI

Resource Public Key Infrastructure.

Research:

- cryptographic authorization
- Route Origin Authorizations
- origin validation
- routing trust

### SAV

Source Address Validation.

Research:

- source-address legitimacy
- ingress filtering
- uRPF
- distributed validation

### SAVNET

Source Address Validation networking architecture.

Research:

- interdomain SAV
- information exchange
- incremental deployment
- autonomous networks
- distributed routing security

## ANARCHY question

How can independent autonomous networks establish enough shared information
and trust to cooperate on routing security without requiring one permanent
central controller?
