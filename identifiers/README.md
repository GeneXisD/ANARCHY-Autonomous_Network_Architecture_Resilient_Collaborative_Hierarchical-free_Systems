# Machine-Readable Identifiers

ANARCHY research includes identifiers that provide stable machine-readable
identity for artifacts.

Systems to compare:

- NIST PubID
- DOI
- ISBN
- ISSN
- ORCID
- SPDX identifiers
- Package URLs (PURL)
- CPE
- Git object IDs
- Git commit SHA
- OCI content digests
- IPFS CIDs
- URI
- URN
- UUID

Research questions:

- What does the identifier identify?
- Is it persistent?
- Does it encode version?
- Does it encode provenance?
- Can it identify content cryptographically?
- Can it identify an author?
- Can it identify a license?
- Can relationships between artifacts be represented?
