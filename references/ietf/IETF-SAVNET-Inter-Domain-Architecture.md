## ANARCHY relevance

SAVNET is relevant to ANARCHY because it explores mechanisms through which
independently operated networks can exchange information that improves
source-address validation.

The architecture is particularly relevant to:

- autonomous network participants
- interdomain information exchange
- distributed trust
- incremental deployment
- resilience
- routing security
